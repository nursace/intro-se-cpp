# Lab 06 — Указатели и ссылки

1. `swap_ref.cpp` — `void swap_values(int& a, int& b)`; показать обмен.
2. `swap_ptr.cpp` — `void swap_values(int* a, int* b)`; при `nullptr` ничего не делать.
3. `max_ref.cpp` — `int& max_ref(int& a, int& b)` (при равенстве — `a`); через ссылку записать `100` в максимум.
4. `print_roster.cpp` — `void print_roster(const vector<string>& names)`; читать `n` имён, печатать по строке.
5. `maybe_set.cpp` — `void maybe_set(int* p, int value)`; демо с адресом и с `nullptr`.
6. `normalize.cpp` — `void clamp_in_place(int& score)` в диапазон 0…100.
