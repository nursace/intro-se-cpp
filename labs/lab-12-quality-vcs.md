# Lab 12 — Качество и Git

1. Взять проект lab-11 (или эквивалент), `git init`, ≥4 осмысленных commit.
2. Сохранить `git log --oneline` в `HISTORY.txt`.
3. Рефакторинг без смены поведения (вынести разбор команд из `main`); commit `Refactor command loop`.
4. Сборка с `-Wall -Wextra` без warnings.
5. `CHECKLIST.md`: требования актуальны, модули разделены, тесты ок, ≥4 commit, есть README как собрать.
6. `REVIEW.md` (5–8 строк): что бы попросили исправить у одногруппника.
